Документ для проверки

Проверяем ссылку…

Эта ссылка для конкретного человека. Войдите через Telegram — откроется, только если ваш ник совпадает с тем, кому отправили.

В Telegram откроется бот — нажмите в нём «Start» и вернитесь сюда, страница продолжит сама. Не открылся? Открыть бота.

Вошли не под тем аккаунтом? Сменить аккаунт Telegram.

Документы можно открыть только один раз: после нажатия «Открыть» они будут видны 90 секунд, а на сервере удалятся сразу. Каждая страница подписана вашим ником; файлом не скачать. Расшифровка идёт в вашем браузере.
